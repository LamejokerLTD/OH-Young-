# Local Whisper：另一台電腦安裝說明

版本：2026-09-21，Windows x64 線上安裝包。

## 安裝

1. 把 ZIP 複製到新電腦，按右鍵選「解壓縮全部」。
2. 把解壓後的 `Local-Whisper` 資料夾放在要長期保留的位置，例如「文件」資料夾。安裝後請保持此資料夾的位置。
3. 進入資料夾，雙擊 `install.bat`；或直接雙擊 `start.bat`，首次啟動會自動安裝。使用一般使用者權限即可；安裝過程需要網路。
4. 等待安裝成功。程式會準備 Python 3.12、建立獨立環境、安裝語音處理套件，並建立桌面及開始功能表捷徑。如果已有另一份安裝的同名捷徑，新捷徑會附上資料夾名稱，舊捷徑會保留。
5. 雙擊桌面捷徑，瀏覽器自動開啟本機頁面（預設 `http://127.0.0.1:8000`；若該埠被其他程式使用，會自動改用 8001–8005），上傳音訊或影片開始辨識。

請在解壓後執行安裝，不要直接在壓縮檔預覽中執行。首次辨識另需下載約 3 GB 的 Whisper Large-v3 模型；等待畫面中的下載／載入進度。模型完整下載後可離線辨識。

## 電腦需求

- Windows 10／11，64 位元 x64；本包不適用 macOS、Linux 或原生 Windows ARM64。
- 建議至少 16 GB RAM，預留至少 15 GB 磁碟空間，另加上傳影片與暫存檔空間。
- 支援 NVIDIA GPU 加速，需電腦已有可用的 NVIDIA 驅動；安裝器會安裝 Python 使用的 CUDA 函式庫。沒有可用 GPU 時可用 CPU，但 Large-v3 辨識較慢。
- 安裝時需可連線 Python 官方網站與 Python 套件來源；首次模型下載需連線 Hugging Face。
- 這是精簡線上安裝包，不含 Python、套件、Whisper 模型或這台電腦的虛擬環境。

## 使用與下載

辨識完成後，頁面 `03 / OUTPUT` 的 `EXPORT / 下載逐字稿` 提供 SRT、TXT、帶時間碼 TXT、VTT、JSON。開始下一份辨識或停止服務前，請先下載要保留的結果。

桌面捷徑使用背景啟動；關閉瀏覽器分頁只關閉畫面，服務仍可在背景運作。再次點捷徑可開啟既有頁面。重新啟動電腦會停止背景服務並清除當次暫存，已下載的檔案不受影響。

此版本包含 Whisper Large-v3、降速重試、人聲增強與雙軌辨識。人聲增強與雙軌模式會安裝額外音訊處理套件；雙軌模式需執行兩次辨識，因此較慢。

## 如果無法啟動

- 先確認 `install.bat` 顯示安裝成功；網路中斷後可再次執行。
- 瀏覽器未自動開啟時，先查看 `logs/launcher.out.log`；通常使用 `http://127.0.0.1:8000`，若 8000 被占用則依序嘗試 8001 到 8005。
- 若 Windows Script Host 被公司政策停用，可雙擊 `start.bat` 診斷啟動；此方式會保留命令視窗，工作期間保持開啟。
- 若只需重建捷徑，執行 `install-shortcuts.bat`。同名捷徑若屬於另一個資料夾，安裝器會建立附有資料夾名稱的新捷徑。
- 錯誤紀錄在程式資料夾的 `logs`。安裝失败時可提供安裝視窗的最後錯誤，不必傳送錄音。

## 本包的驗證範圍

交付前檢查套件依賴可解析、安裝腳本語法、捷徑重複建立、解壓後的背景服務與五格式下載，以及既有回歸測試。這些是在目前 Windows 電腦執行，不代表已在你尚未提供的另一台電腦上完成全新安裝測試。
